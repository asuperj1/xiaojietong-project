# 校捷通 · 3B QLoRA 微调训练报告（C4 初稿）

> 日期：2026-09-10 ｜ 执行：成员3 ｜ 状态：✅ 首次试跑成功（LoRA adapter 已产出）

## 1. 目标

用校园知识问答数据对轻量基座做 **QLoRA 指令微调**，验证「数据构建 → 训练 → 评估」流水线可跑通，为端侧/服务端部署与答辩提供模型产物。

## 2. 环境

| 项 | 值 |
|---|---|
| GPU | NVIDIA **RTX 4080 SUPER 16GB**（驱动 595.97 / CUDA 13.2） |
| 环境 | conda `xjt-train`，Python 3.11.15 |
| 框架 | torch **2.6.0+cu124**、transformers **5.17.0**、peft 0.20.0、bitsandbytes 0.50.2、datasets 5.0.1、accelerate 1.15.0 |
| 基座模型 | **Qwen2.5-3B-Instruct**（本地 `E:\models\Qwen2.5-3B-Instruct`） |

## 3. 数据

- 来源：`ai/finetune/data/train.jsonl`（由 `build_dataset.py` 从内置种子 + `db/sql/99b·99d` 知识库构建）
- 规模：**1780 条**（基础问答 178 条 × 问法/多轮扩增）
- 格式：Qwen2.5 `messages`（system/user/assistant）

## 4. 训练配置

| 参数 | 值 |
|---|---|
| 方法 | QLoRA（4bit nf4 + LoRA） |
| LoRA | r=16, alpha=32, dropout=0.05；target: q/k/v/o + gate/up/down_proj |
| 可训练参数 | **29,933,568 / 3,115,872,256（0.96%）** |
| epochs | 1 | 
| batch | per_device=1, grad_accum=8（等效 batch 8） |
| max_len | 768 |
| lr | 1e-4，cosine，warmup 20 steps |
| 精度 | bf16 |

## 7. 产物与后续

- **产物**：`ai/finetune/out/qwen3b-lora`（LoRA adapter，未入库——`out/` 已在 `.gitignore`）
- **C5 待做**：合并 LoRA 权重 → 导出 **GGUF** → 交后端在 **Ollama** 载入（`model_client.py` 指向）→ `chat/send` 走真实模型
- **优化方向**：扩充高质量数据、多轮/长文样本、按 assistant 段做 loss mask、增大 r/epochs、加入评估集指标（准确率/BLEU/人工打分）

## 8. 复现命令

```bash
# 环境
conda activate xjt-train          # Python 3.11 + torch cu124 + peft/bitsandbytes

# 数据
python ai/finetune/build_dataset.py

# 训练（约 11 分钟/epoch on RTX 4080S）
python ai/finetune/train.py --base_model E:/models/Qwen2.5-3B-Instruct \
  --output ai/finetune/out/qwen3b-lora --epochs 1 --max_len 768 --batch_size 1 --grad_accum 8

# 评估
python ai/finetune/eval.py --base_model E:/models/Qwen2.5-3B-Instruct \
  --model ai/finetune/out/qwen3b-lora --n 10
```

> 备注：`train.py` 已适配 transformers 5.x（弃用 `warmup_ratio`，改用 `warmup_steps`）。
