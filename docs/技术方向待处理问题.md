**CAC-25 修复建议**：
1. 引入中文分词（`jieba`）或 **2-gram 滑窗**切分后再 `LIKE`；
2. 更彻底：降级路径改用 MySQL `ngram` 全文索引（`MATCH ... AGAINST`，与 `CAC-05` 同批）；
3. 最低成本改法：长句先**去标点**并取「前 N 字 + 2-gram 组合」作为多个 term，避免整串匹配。
