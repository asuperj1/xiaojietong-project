### 1.2 三个最危险的发现

| # | 发现 | 实测/静态证据 | 后果 |
|---|---|---|---|
| 1 | **二手审核闭环断裂**：审核只回写 `audit_status`，但**所有读路径都不过滤它** | `secondhand_dao.cpp:9-27` 无 `audit_status` 条件 + **实测**：发布 → `audit_status=0`（待审）→ 立即出现在 `GET /secondhand/items` | 违规内容（广告/联系方式/外链）**审核后照样全网可见**；Agent 工具链发布的商品**根本不过审**（`agent_executor.py:278-291`） |
| 2 | **登录限流可被伪造 `X-Forwarded-For` 完全绕过** | `ratelimit.py:91-96` 无条件信任 XFF；**实测**：每次换一个伪造 IP 连发 15 次登录 → **0 次 429**；对照同 IP 连发 12 次 → 第 11 次起 429 | SEC-10 花大力气加的防爆破能力**等于零**：攻击者一行 header 即可无限爆破口令/code |
| 3 | **dev 默认配置下 JWT 密钥写在仓库里，且 `env` 默认就是 `dev`** | `config.py:8,22,36`：`_DEFAULT_JWT_SECRET = "xjt-dev-secret-change-me-at-least-32b"`，安全校验只在 `is_prod` 分支生效 | 任何能读仓库的人可**离线签发任意用户（含管理员）token**；按文档 `uvicorn app.main:app` 起的演示机/内网机全部处于该状态 |

### 1.3 一句话结论

> **上轮的"高危漏洞"基本修完了，但"修复本身"缺少闭环验证**：审核修了写没修读、限流修了计数没修取 IP、契约改了响应体没兜住校验错误。

## 2. P0 · 阻断上线（6 项）

### [P0] SEC-17 · 登录限流可被伪造 `X-Forwarded-For` 完全绕过
- **位置**：`backend/app/core/ratelimit.py:91-96`
- **证据**：
```python
def client_ip(request: Request) -> str:
    """取客户端 IP，优先信任反向代理透传的 X-Forwarded-For 首段。"""
    forwarded = request.headers.get("x-forwarded-for", "")
    if forwarded:
        return forwarded.split(",")[0].strip()      # ← 无代理白名单校验，客户端可任意伪造
    return request.client.host if request.client else "unknown"
```
  实测（`tools/audit_probe_260912.py` 探针 1/2）：
```text
探针 1 · 15 次登录（每次不同伪造 XFF）→ [200 ×15]   429 次数：0      ← 完全绕过
探针 2 · 同 IP 连续 12 次登录        → [200×10, 429, 429]          ← 限流本身有效
        429 响应体：{"code":1010,"message":"操作过于频繁，请 60 秒后重试"}
```
- **影响**：`/auth/wechat-login`（10 次/分钟）与 `/auth/refresh`、`/upload`、`/chat/send`、`/agent/tasks` 的专属限流**全部可绕过**；配合 dev 态 mock 登录（SEC-02 的降级路径）可批量造号。
- **建议**：① 仅在**直连可信代理**时信任 XFF（配置 `trusted_proxies` 列表，或改读 `request.client.host`）；② 反向代理必须**覆盖**而非追加 XFF（`proxy_set_header X-Forwarded-For $remote_addr;`）；③ 关键接口（登录）增加**按账号维度**的第二把锁（如按 `openid/code` 前缀限流），避免仅靠 IP。
- **状态**：新增（SEC-10 的修复不完整）

- **位置**：`backend/app/core/config.py:8`（密钥常量）、`:22`（`env: str = "dev"`）、`:36`（默认使用该密钥）、`:98-116`（校验仅对 `is_prod` 生效）

- **状态**：新增
