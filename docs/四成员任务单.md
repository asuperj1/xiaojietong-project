## 每周协作节奏

1. **每天**：群里一句话进度/卡点（"今天做了 F4，卡在 SSE 没渲染完"）。
2. **每周五**：各 feature 并 `dev`，跑一次「演示闭环」，README 里程碑表打勾。
3. **改接口**：先改 `docs/api.md` 再动代码；前后端以它为准。
