> ⇒ 直接 `ALTER TABLE user ADD UNIQUE KEY uk_user_student_no (student_no)` **必定报错**
> `ERROR 1062 Duplicate entry '' for key`。正确顺序：
> ```sql
> -- ① 空串先转 NULL（唯一索引允许多个 NULL，但不允许多个 ''）
> UPDATE user SET student_no = NULL WHERE student_no = '';
> -- ② 再查一遍真重复（同号多人），有则先人工处理，不能直接加索引
> SELECT student_no, COUNT(*) c FROM user WHERE student_no IS NOT NULL
>  GROUP BY student_no HAVING c > 1;
> -- ③ 幂等加索引
> ALTER TABLE user ADD UNIQUE KEY uk_user_student_no (student_no);
> -- ④ 业务侧约定：未绑学号一律写 NULL，不要写 ''，否则多人都会撞 ''
> ```
