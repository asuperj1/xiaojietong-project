### 9.2 学号允许学生自改，但**限频**

| 项 | 方案（产品方已确认） |
|---|---|
| 频率 | **1 次 / 7 天**（一周一次） |
| 唯一性 | `UNIQUE KEY uk_student_no` |

| 审计 | 写 `audit_log` |
| 超频 | `BizError(3001, "学号修改过于频繁，请 X 天后重试")` |

> 💡 **设计要点**：“格式因校而异”恰恰是可迁移引擎的典型场景 —— 代码侧**只做长度与非空**的通用校验，
