# 校捷通 · 前端页面规格书（成员1 执行蓝本）

> 目标：让页面开发**不用自己想功能/按钮**，照本页做即可；每个控件背后都标注对应后端接口（均已在 `docs/api.md` 登记并实测）。
> 全局约定：登录后请求头带 `Authorization: Bearer <token>`；统一响应 `{code,message,data}`，code≠0 弹 toast(`message`)。

---

## 0. 起步三件事（先做，做完全队能联调）

1. **全局文件**：`app.json`（页面注册+TabBar）、`app.js`（onLaunch 检查 token）、`app.wxss`（主题色 #4A90D9）
2. **请求封装** `services/request.js`：
   - `request(path, {method, data})` → 带 token、解 `{code,message,data}`、code=2001/2002 跳登录页
   - `sseRequest(path, data, {onChunk,onDone,onError})` → 用 `wx.request enableChunked` 解析 SSE（`event: chunk / done`）
3. **登录页 `pages/auth/login`**（小程序无原生跳转授权，用"微信一键登录"按钮走 code 换 token）
   - 按钮【微信一键登录】→ `wx.login()` 取 code → `POST /auth/wechat-login {code}` → 存 token/refresh_token/user → 跳首页

## 2. AI 对话页 `pages/chat/chat`（Tab·核心卖点，SSE）

| 控件 | 类型 | 说明 / 动作 → 调接口 |
|---|---|---|
| 消息区 | scroll-view | 上下气泡（user 右侧 / assistant 左侧），assistant 支持 markdown 渲染 |
| 输入框 | textarea | 多行输入 |
| 【发送】钮 | button | 收起键盘 → `sseRequest("/chat/send", {content})` 逐字渲染 chunk，done 后结束 |
| 【停止】钮 | button | 生成中显示，`wx.request.abort` |
| 快捷指令行 | chips | 点 → 把 `quick_command` 模板当内容发送 |
| 顶部【+ 新会话】 | icon | `conversation_id=null` 新建 |
| 顶部【历史】 | icon | 弹层列表 → `GET /chat/conversations`；点某条载入 |
| 长按消息【👍👎】 | 反馈 | `POST /chat/feedback {target_type:"answer",target_id,rating:4/2}` |

**SSE 渲染逻辑**：收到 `event:sources` 存引用来源(可折叠)；`event:chunk` 追加文本；`event:done` 收尾。失败 `event:error` 显示 message。

## 13. 交付节奏（每页验收标准）

- **每完成一页** = 能调后端真数据渲染 + 按钮动作有结果（不是写死 mock）。
- 联调用**同一份数据库**：后端 `uvicorn :8000`，小程序开发者工具"不校验合法域名"勾上连 `http://127.0.0.1:8000`。
- 代码走 `feature/frontend` 分支，只改 `miniprogram/`。
